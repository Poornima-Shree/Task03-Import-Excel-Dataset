# Student Performance Analysis Using Python

## 📌 Project Overview

This project focuses on importing, exploring, and analyzing an Excel dataset using Python. The dataset contains students' examination scores in Mathematics, Reading, and Writing.

The main objective is to understand student performance through data analysis and visualization.

## 📂 Dataset Information

- **Dataset Name:** Students Performance in Exams
- **Total Records:** 1000 Students
- **Total Columns:** 8
- **File Format:** Excel (.xlsx)

**Original Dataset Source:** [Kaggle – Students Performance in Exams](https://www.kaggle.com/datasets/spscientist/students-performance-in-exams)

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Visual Studio Code

## 📊 Project Activities

1. Imported the Excel dataset using Pandas.
2. Displayed the first and last five rows.
3. Explored dataset information and dimensions.
4. Checked missing values and duplicate records.
5. Generated descriptive statistics.
6. Calculated average scores for each subject.
7. Analyzed student performance using data visualization.

## 📈 Data Visualizations

The following visualizations were created:

### 1. Bar Chart – Average Scores by Subject
Compares the average Mathematics, Reading, and Writing scores.

### 2. Histogram – Distribution of Mathematics Scores
Shows how Mathematics scores are distributed among students.

### 3. Correlation Heatmap
Displays the relationships between Mathematics, Reading, and Writing scores.
